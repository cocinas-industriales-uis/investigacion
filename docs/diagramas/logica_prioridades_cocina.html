Notas técnicas para el firmware

Temporizador de confirmación: P0, P1 y P2 actúan de forma inmediata (llama + >90°C no se explica por vapor). P3 también es inmediato cuando el ΔT/s es alto. Solo P3 por temperatura (60–90°C) y P8 requieren CONFIRM_MS = 10000 ms de condición sostenida antes de escalar, para evitar falsos positivos por vapor o fogón normal. Envío MQTT: el intervalo se decide con la prioridad detectada, no la confirmada: P2/P3 reportan cada 0.5 s desde el primer instante y el escalado a P0–P3 envía al momento. El mensaje incluye confirmando para distinguir «detectado» de «confirmado».

ΔT/s — velocidad de cambio: Array circular de las últimas 10 lecturas. Si la diferencia entre la lectura más reciente y la más antigua supera DELTA_UMBRAL = 2.0 °C/s con llama activa, escala inmediatamente a P3 sin esperar el umbral absoluto.

Escala de gas en % LEL para MQ-2: Correlación aproximada para GLP — raw 200 ≈ 10% LEL · raw 400 ≈ 20% LEL · raw 750 ≈ 40% LEL. Calibrar con gas real en el prototipo físico.

Presión diferencial: El BMP280 entrega hPa. Tomar la lectura inicial como referencia y comparar diferencialmente: ΔP > +8 hPa respecto al arranque activa P6. Nunca comparar contra valor absoluto.

P0 y chispas eléctricas: En P0 apagar también los motores DC detiene posibles chispas de las escobillas. El relay de la válvula ya corta el gas. Es el único estado donde el sistema queda completamente inerte.

Cómo leer este diagrama: Cada rectángulo es un estado del sistema. Las flechas rojas sólidas son escaladas de emergencia — ocurren de forma inmediata sin temporizador. Las grises son transiciones normales que pueden requerir confirmación. Las grises discontinuas son condiciones adicionales que causan escalada desde un estado ya activo. Toda transición de vuelta a NORMAL requiere que la condición haya desaparecido y que el sistema confirme durante CONFIRM_MS = 10000ms.
